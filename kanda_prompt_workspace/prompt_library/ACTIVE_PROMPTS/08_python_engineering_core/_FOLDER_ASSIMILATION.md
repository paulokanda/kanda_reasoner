# FOLDER ASSIMILATION CARD

Folder: 08_python_engineering_core
Card type: routing metadata
Status: active metadata card

## Purpose

This folder groups core Python engineering prompts for implementing, reading, repairing, and maintaining Python code in a controlled way.

## Use when

Use this folder when the task involves:

- Python file changes;
- import errors;
- function or class implementation;
- module-level bug repair;
- script creation;
- command-line execution behavior;
- compatibility with the user's Python-reading workflow.

## Routing role

This folder identifies when actual Python engineering context is needed. It should not be loaded for pure prompt audit, planning, or non-code explanation tasks.

## Companion folders

Common companion folders:

- 04_box_architecture_and_boundaries for owner-box boundaries.
- 05_patch_delivery_and_validation for install and validation scripts.
- 06_refactor_and_architecture_hardening for structural changes.
- 09_python_quality_security_observability for tests, safety, logging, and risk review.
- 10_python_api_data_async_config for API, data, async, or config work.

## Not responsible for

This folder does not own release readiness, prompt audit, freeze decisions, or live app integration planning.

## Load rule

Load only when the task requires Python code reasoning or Python file modification.
