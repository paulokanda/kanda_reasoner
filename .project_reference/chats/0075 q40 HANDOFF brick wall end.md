5. FROZEN ARCHITECTURAL BASELINE

The following principles are now protected.

Tool versus Project

KANDA Reasoner Tool is reusable machinery.

The selected Active Project owns its source, generated project results, durable project evidence, transactions, receipts, Error Memory, and Freeze Memory.

Self-hosting does not collapse logical Tool and Project identity even when their physical roots are equal.

Box Architecture

Every governed release declares exactly one primary box.

Supporting touches must be bounded and must identify their owner, reason, and public contract.

Cross-box access must use a public contract, facade, controller route, command, event, bridge, or adapter.

Private reach-in and cross-box private-state mutation are forbidden.

Mutable state

Every mutable state object has one canonical owner.

Readers and authorized mutation routes must be explicit.

Duplicate mutable-state writers are forbidden.

MCard

KANDA Reasoner is the reusable card machine.

The Active Project owns the inserted card and its durable results.

Project or target changes invalidate card-specific Tool state.

Late asynchronous results must prove current project, target, operation, hash, and generation.

Open transactions block switching and eject.

Terminal completion or verified rollback is required before card eject.

Eject clears Tool memory and preserves project-owned results.

Paths and evidence

Project source remains under the Active Project root.

Durable project support remains under the selected project sibling support root.

Preview remains durable project support.

Shadow and disposable staging remain transient.

Generated archives are evidence, not source authority.

Daily-work never owns durable truth.

Freeze Memory

Project-specific frozen memory remains under:

<project>_show_project_to_AI/project_freeze_after_update/frozen_features_memory

Project-specific frozen memory must never be stored inside project_freeze_ledger.

Preview Freeze Entry remains read-only.

Confirm and Write requires explicit human confirmation.

Automatic frozen-memory writes remain forbidden.

After a local freeze write, the startup Freeze context must be refreshed.

Patch delivery

The exact final downloadable ZIP must pass the canonical patch ZIP validator.

Every changed file must appear exactly once in the Q31 coverage map.

Required validators must be explicitly inventoried.

Installation, validation, freeze preparation, and human freeze are separate phases.

A success marker from one phase must not be incorrectly required from another phase’s output stream.

PowerShell

User-facing and packaged PowerShell must contain no else and no elseif.

Use independent if blocks, guard clauses, explicit state flags, and early return.

Do not use an unnecessary outer & { ... } wrapper.

If the terminal displays >>, cancel the incomplete statement with Ctrl+C before running another block.
