Is it really an error?

For Python runtime: not always. Python may still run normally.

For architecture validation: yes, it matters, because the project analyzer cannot know which file is the canonical owner of that symbol.
Why it is important

ambiguous imports
wrong autocomplete in PyCharm
wrong API map for future refactors
duplicate documentation ownership
hidden bugs when using from package import *
confusion between real modules and shim/backup modules
future refactor risk

1. keep the symbol in the canonical/original module
