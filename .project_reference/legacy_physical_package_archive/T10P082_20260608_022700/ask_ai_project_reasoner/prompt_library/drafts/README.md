# Prompt Drafts

Store prompt drafts here before they become active library prompts.

Rules:
- All edits start as drafts.
- Drafts do not affect runtime behavior.
- Drafts do not modify source code.
- Drafts do not update active governance.
- Validate and review drafts before copying them to active.

Recommended naming:
<prompt_id>_draft_<YYYYMMDD_HHMMSS>.md
