# Prompt Metadata

Store prompt metadata sidecars here.

A metadata file describes a prompt so Tab 9 can display:
- name
- version
- category
- explanation
- how it works
- file creation behavior
- risks and mitigations
- copy/edit policy
- project-agnostic placeholders

Recommended naming:
<prompt_id>.meta.json

Schema reference:
kanda_reasoner_app/templates/prompt_library_templates/PROMPT_METADATA_SCHEMA.json
