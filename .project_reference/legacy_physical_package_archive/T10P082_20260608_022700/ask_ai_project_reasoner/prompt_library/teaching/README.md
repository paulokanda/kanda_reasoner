# Prompt Library Teaching Assets

This folder contains text-only assets that teach an AI how to create or update prompts for Tab 9 Prompt Engineering Library.

Scope:
- Explain Tab 9 logic to an AI.
- Explain how prompt files, metadata files, groups, stacks, profiles, overlays, packs, QA files, and release files fit together.
- Provide a copyable request prompt for creating or updating prompt-library assets.

Hard boundaries:
- These files do not edit source code.
- These files do not edit active governance.
- These files do not run prompts automatically.
- These files do not change Tabs 1 through 8.

Use this group when asking another AI to add a prompt, update a prompt, add metadata, or place a prompt into a Tab 9 dashboard group.
