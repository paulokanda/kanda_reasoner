Detailed Audit & Recommendations
1. Threshold & Trigger (500 lines)

Current: Hard threshold at 500 lines.

State-of-the-art: 500 lines is a widely accepted threshold, but the recommendation is to consider splitting at 300-500 lines depending on complexity. Some projects use 1500 lines as an upper bound for gradual refactoring.

Recommendation: Keep 500 lines but add:

    Complexity trigger — if a module has >10 top-level functions/classes or >5 distinct responsibilities, split even if under 500 lines.

    Gradual exception — allow >500 lines if actively being refactored (tracked in a refactoring backlog).

## Task 0 — Audit (expanded)

### 0.1 Import Analysis
- List all modules that import this file (use `grep -r "from.*import"` or `pylint --import-graph`)
- Identify if any imports are from the module being refactored (internal dependencies)
- Flag any star imports (`from module import *`) — they make refactoring unsafe

### 0.2 Test Coverage Assessment
- Document existing tests (by name, what they cover)
- Identify gaps — critical paths without test coverage
- If coverage < 80%, recommend adding characterization tests before refactoring

### 0.3 Public API Inventory
- List all symbols currently imported by other modules
- Document what `__all__` currently exposes (if anything)
- Note: if `__all__` is missing, assume ALL top-level symbols are public

### 0.4 Complexity Metrics
- Lines of code (physical vs logical)
- Number of top-level functions, classes, constants
- Cyclomatic complexity (use `radon cc` or `wily`)
- Identify "God objects" or "God modules"[reference:13]

### 0.5 Responsibility Clustering
- Group functions/classes by responsibility (using AST analysis or manual review)
- Identify which groups are cohesive and can be extracted together[reference:14]

### 0.6 Risk Assessment
- Circular import risk: high/medium/low
- Breaking change risk: high/medium/low
- Test coverage adequacy: sufficient/insufficient

### 0.7 Blind Spots
- Dynamic imports (`__import__`, `importlib`)
- Runtime code generation
- Monkey-patching or dynamic attribute assignment
