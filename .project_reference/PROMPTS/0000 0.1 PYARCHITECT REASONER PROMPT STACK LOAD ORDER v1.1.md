## Code documentation and module size rules

**Docstring requirement**  
Every Python module, class, function, and method MUST contain a docstring.  
- Module docstring: describes the purpose of the module.  
- Class docstring: describes the class responsibility and usage.  
- Function/method docstring: describes parameters, return values, and side effects.  
Docstrings must follow the Google or NumPy style (consistent within the project).  
No `pass`‑only bodies without a docstring are allowed.

**Module line limit**  
- Preferred maximum module length: **400 lines** (excluding blank lines and comments).  
- Absolute maximum: **500 lines**.  
- If a module exceeds 500 lines, the Large Module Refactor Protocol (`0000 5.7`) MUST be invoked before any further changes are made to that module.  
- Modules between 400 and 500 lines are allowed but should be considered candidates for future splitting during refactoring sessions.
