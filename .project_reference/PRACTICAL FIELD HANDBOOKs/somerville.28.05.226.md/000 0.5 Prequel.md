### [0:00 – 2:00] Opening

Waves in, wisdom out. Hello.

This is the **prequel** – the class before the first real lesson.  
If you have never written a line of code in your life, do not worry. I will hold your hand for every single click.

By the end of this 12‑lesson series, you will write Python code that loads an EEG file, cleans the signal, finds triggers, cuts epochs, and makes beautiful plots. But first, you need **tools** – like a carpenter needs a hammer and a saw.

Today we will install four things:

1. **Python** – the language we speak to the computer.
2. **Jupyter Notebook** – the program where we write and run code, like a smart notepad.
3. **MNE‑Python** – a special library (a collection of tools) for EEG analysis.
4. **matplotlib** – a library for making graphs.

We will do this step by step on **Windows 11**. I am not in a hurry. Pause the video whenever you need.

### [2:00 – 4:00] What is Python?

[SCREEN: Draw a stick figure talking to a computer. Label “You” and “Computer”. Add a translator bubble: “Python”.]

A computer does not understand human language – English, Spanish, Chinese. It only understands **binary**: zeros and ones. But we cannot write zeros and ones – it would take forever.

So someone created **Python**. Python is a **programming language** – a middleman. You write instructions in Python (which looks almost like English), and the computer translates them into binary and does the work.

Think of Python like a translator. You say “load the EEG file” in Python, the computer understands and loads it.

We need to install Python on your computer. But **important**: MNE‑Python, the EEG library, only works with **Python version 3.10**. Not 3.11, not 3.12 – exactly 3.10. We will install that specific version.

### [4:00 – 7:00] Installing Python 3.10 – step by step

[SCREEN: Show Windows 11 desktop. Open a web browser (Edge or Chrome).]

Step 1 – Download Python 3.10.

Go to the website `python.org`.  
Move your mouse to “Downloads”. A menu appears. Do not click the big yellow button – that gives the latest version. We need an older one.

Instead, click on “Windows” under “Downloads”. Then scroll down until you see **“Python 3.10.11”** – that is the last version of Python 3.10.  
Click the link that says **“Windows installer (64-bit)”**.

[SCREEN: Highlight the correct link with an arrow.]

The file will download – it is called something like `python-3.10.11-amd64.exe`. Open it when finished.

Step 2 – Install Python 3.10.

A window pops up. **Look at the bottom of the window.** You see a checkbox that says “Add Python to PATH”. It is very important. **Click that checkbox** – it must have a tick.

[SCREEN: Zoom in on the checkbox, show a tick appearing.]

Then click “Install Now”. Wait. You will see a green progress bar. When it finishes, you will see “Setup was successful”. Close the window.

Now Python 3.10 is installed.

### [7:00 – 9:00] What are libraries? What is pip?

[SCREEN: Draw a toolbox with separate compartments labelled “MNE”, “matplotlib”, “NumPy”.]

Python by itself can do basic math and text. But to read EEG files, filter signals, or plot graphs, we need **extra tools**. These are called **libraries** or **packages** – like specialised screwdrivers in a toolbox.

- **MNE‑Python** – the EEG library. It knows how to open `.edf` files, find events, cut epochs, average, etc. Without MNE, you would have to write everything from scratch – impossible.
- **matplotlib** – the plotting library. It makes graphs, topographies, time series.
- **Jupyter** – the notebook environment. It is also a library that we install.

To install a library, we use a Python tool called **pip**.  
`pip` stands for “Pip Installs Packages” – a funny name. Think of `pip` as a delivery service: you say `pip install X`, and it downloads X from the internet and puts it in the right place.

We will open a **Command Prompt** – a black window where we type commands.

### [9:00 – 12:00] Opening Command Prompt and installing libraries

[SCREEN: Show Start menu, type “cmd”, open Command Prompt. A black window appears.]

[SCREEN: Show the black window with a blinking cursor.]

Now we will install the three libraries. Type each command and press Enter. Wait for each to finish before typing the next.

First command:

`pip install jupyter`

Second command:

`pip install mne`

This installs MNE‑Python. Again wait. MNE is big – it may take a minute.

Third command:

`pip install matplotlib`

This installs the plotting library.

If any command gives an error, try typing `python -m pip install ...` instead. But usually it works.

Close the Command Prompt when finished.

### [16:00 – 20:00] Line‑by‑line code explanation

[SCREEN: In the first cell, type line by line. Number the lines on screen.]

**Line 1:** `import mne` – loads the EEG library.

**Line 2:** `import numpy as np` – loads NumPy, a library for mathematics (we need it for the amplitude calculation).

**Line 3:** `import ipywidgets as widgets` – loads the library that creates buttons and sliders.

**Line 4:** `from IPython.display import display` – lets us show the button on the screen.

**Line 5:** `EDF_FILE = "subject_01.edf"` – a variable that stores the file name. If your file has a different name, change it here.

**Line 6:** `SECONDS_TO_PLOT = 4` – we will analyse the first 4 seconds of the recording.

**Line 7:** `CHANNELS_TO_PLOT = 10` – how many channels to show in the preview.

Now we define a function to load the EEG file:

**Line 8:** `def load_eeg_data(edf_path):` – start of a small block of code that loads the file.

**Line 9:** `print(f"📂 Loading EEG data from '{edf_path}'...")` – a message to see progress.

**Line 10:** `raw = mne.io.read_raw_edf(edf_path, preload=True)` – the command that actually reads the `.edf` file.

**Line 11:** `print(f"   ✅ Data loaded. Shape: {raw.get_data().shape}")` – shows how many channels and samples.

**Line 12:** `return raw` – gives the loaded data back to the rest of the program.

Now a function to cut the first few seconds:

**Line 13:** `def select_data_slice(raw, seconds):`

**Line 14:** `n_samples = int(seconds * raw.info['sfreq'])` – converts seconds to number of data points (samples).

**Line 15:** `data_slice, times_slice = raw[:, :n_samples]` – takes the first `n_samples` from all channels.

**Line 16:** `print(f"✂️  Selected the first {seconds} seconds of data.")`

**Line 17:** `return data_slice, times_slice, raw.info`

Now the function that runs when you click the button:

**Line 18:** `def on_button_clicked(b):`

**Line 19:** `print("\n🎨 Generating topographic map...")`

**Line 20:** `rms_amplitude = np.sqrt(np.mean(data_slice**2, axis=1))` – calculates the average power (RMS) for each channel.

**Line 21:** `fig = mne.viz.plot_topomap(rms_amplitude, raw.info, show=False)` – draws the brain map.

**Line 22:** `fig.suptitle(f'EEG Amplitude Map (RMS) - First {SECONDS_TO_PLOT} seconds')`

**Line 23:** `fig.show()`

**Line 24:** `print("   ✅ Topographic map displayed.")`

Finally, the main part that runs everything:

**Line 25:** `raw_data = load_eeg_data(EDF_FILE)`

**Line 26:** `data_slice, times_slice, info = select_data_slice(raw_data, SECONDS_TO_PLOT)`

**Line 27:** `button = widgets.Button(description=f'Show Amplitude Map for first {SECONDS_TO_PLOT}s', button_style='success')`

**Line 28:** `button.on_click(on_button_clicked)`

**Line 29:** `display(button)`

**Line 30:** `raw_data.plot(n_channels=CHANNELS_TO_PLOT, duration=SECONDS_TO_PLOT, scalings='auto')`

Now press “Run” (the ▶ button). Wait a few seconds.

[SCREEN: Show the plot appearing – a scrolling EEG window, and below it a green button.]

Click the green button. A new window will open with a coloured topographic map of the brain.

That is real EEG. You just wrote your first interactive EEG analysis program.
