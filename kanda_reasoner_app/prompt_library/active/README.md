# Active Prompt Library

Store prompts that are approved for routine manual reuse.

Rules:
- Files here are text prompts, not executable logic.
- A prompt in active is not automatically executed.
- Do not store project source code here.
- Do not store active governance files here.
- Keep prompts project-agnostic by default.

Recommended files:
- *.md
- *.txt

Each active prompt should have a matching metadata sidecar in:
kanda_reasoner_app/prompt_library/metadata/
