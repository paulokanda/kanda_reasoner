# Prompt Library QA

Status: Text-only QA layer for Tab 9 Prompt Engineering Library.

This folder contains manual review checklists for prompt-library quality,
metadata consistency, project-agnostic safety, and release readiness.

Scope:
- Prompts only.
- Metadata only.
- Prompt stacks only.
- Prompt packs only.

Out of scope:
- Source code changes.
- Runtime behavior changes.
- GUI implementation.
- Active governance edits.
- Tabs 1 through 8 behavior.

Use this folder before copying prompts to another AI or exporting a prompt pack.
