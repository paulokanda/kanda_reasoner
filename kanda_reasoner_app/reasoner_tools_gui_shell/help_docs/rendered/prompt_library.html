First-Time User Tutorial

Prompt Library

Find, review, and copy current governed prompts without turning the library into an editor, runtime, or governance owner.

What Prompt Library Means

Prompt Library presents the current active prompt collection in a visual, read-only dashboard.

In plain English: It is a governed bookshelf. You may browse, read, and copy prompts, but you do not edit or run them here.

What This Tab Does

  • Loads the canonical workspace or legacy compatibility fallback
  • Shows one cube for each current prompt group
  • Opens read-only group windows
  • Displays metadata and full prompt text
  • Copies one prompt or a full ordered group stack
  • Opens the selected file location
  • Reloads the current library
1
Use Prompt Library to find, learn, preview, and copy. Authoring and governance remain elsewhere.

Canonical Workspace and Legacy Fallback

The tab prefers kanda_prompt_workspace/prompt_library. When unavailable, it may use the package-owned compatibility library.

The status line reports canonical workspace or legacy compatibility fallback.

Current Prompts Only

The canonical scan is limited to ACTIVE_PROMPTS.

Archived, deprecated, inactive, retired, superseded, and load_type=never entries are hidden.

!
Hidden does not mean deleted. Non-current files may still exist in governed storage.

Reload Canonical Library

Reload current groups, prompt files, metadata, and source status. Reload does not edit files.

The Group Cube Dashboard

Groups define display name, description, color, prompt IDs, copy-stack behavior, and prompt order.

Activate a cube to open its floating read-only group window.

The Group Window

The group window contains the prompt list, metadata panel, full preview, Copy Selected Prompt, Copy Full Group Stack, Open File Location, Close, and status messages.

Metadata and Preview

Metadata may include title, category, relative path, prompt ID, version, status, load type, project-agnostic state, explainer, and how-it-works information.

The full text preview is read-only. Review purpose, assumptions, output expectations, order, and safety boundaries before copying.

Copy Selected Prompt

Copies the currently selected prompt's complete text to the system clipboard. It does not run or send the prompt.

Copy Full Group Stack

Copies every current prompt in the group in group-defined order. Use it only when the target workflow expects the full stack.

Open File Location

Opens the selected prompt's parent folder in the operating-system file browser. It does not grant edit authority.

Status Messages and Reconciliation

Status reports group count, prompt count, source type, source path, opened windows, copies, missing groups, and missing matches.

Canonical group reconciliation removes stale IDs, preserves current catalog order, prevents duplicates, appends current prompts missing from the registry, and adds current folder groups.

Read-Only Governance Boundary

In plain English: The library helps you choose a book. It does not rewrite the master copy or decide how it is governed.

What Success Looks Like

  1. Current groups visible
  2. Correct source status
  3. Group window opened
  4. Metadata and preview visible
  5. Selected prompt copied
  6. Full group stack copied in expected order
  7. Source location opened when needed
  8. No prompt files modified

Common Mistakes

  • Assuming every stored prompt is current
  • Mistaking fallback for canonical source
  • Copying a full group when one prompt is enough
  • Copying without reviewing metadata
  • Treating file location as edit permission
  • Expecting the tab to run prompts

If Something Goes Wrong

Check the source status, canonical workspace, group catalog, metadata status, load type, group IDs, selected prompt, source path, and Reload Canonical Library.

First-Time Checklist

  • Source status read
  • Canonical workspace preferred
  • Current-only behavior understood
  • Correct group and prompt selected
  • Metadata and full text reviewed
  • Smallest correct prompt set copied
  • Clipboard status confirmed
  • No execution or edit authority assumed

Final Rule

Use Prompt Library to find, understand, and copy current governed prompts, but keep authoring, lifecycle changes, routing, validation, and execution in their existing owning workflows.
