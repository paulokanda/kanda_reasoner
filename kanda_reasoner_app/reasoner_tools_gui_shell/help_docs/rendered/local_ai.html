First-Time User Tutorial

Local AI

Select the correct project evidence, ask focused questions, and verify every important answer against files, symbols, and runtime evidence.

What Local AI Means

Local AI is an AI model connected through the KANDA local-model configuration. It answers questions using project information that KANDA has loaded or generated.

In plain English: Local AI is like a private assistant sitting beside your project files. It can explain what it sees, but it does not automatically know the entire project until you give it the correct context.

Local AI answers are guidance. They are not automatic approval to change source code.

What This Tab Does

  1. Select a project.
  2. Run or load project analysis.
  3. Load project JSON evidence.
  4. Ask questions about that evidence.
  5. Show related files and symbols.
  6. Keep conversation history in memory.
  7. Show the exact prompt and diagnostic log when needed.
1
The safest order is Select Project, Run Analysis, confirm the JSON, and then ask a focused question.

Before You Start

  1. Confirm the Project root.
  2. Open Config AI and confirm a local model is available.
  3. Run project analysis or load a current project JSON.
  4. Confirm the JSON track.
  5. Ask one clear question.
  6. Read the evidence and uncertainty, not only the final wording.
!
A correct-looking answer can still be based on the wrong project or old JSON. Check the project path and loaded evidence before trusting the answer.

The Safest First-Time Workflow

Step 1 - Select the project

Click Select Project and choose the project root.

Step 2 - Run analysis

Click Run Analysis. KANDA prepares structured project information for Local AI.

Step 3 - Confirm analysis status

Check Analysis, Generated, JSON track, and the detected and active project profiles.

Step 4 - Confirm the local model

Click Open Config AI.

Step 5 - Ask one focused question

Type a question in the message field and click the arrow button.

Step 6 - Read the answer and evidence

Inspect File evidence, Symbol evidence, Selected detail, Prompt preview, and Log.

Step 7 - Continue or start a new session

Keep the conversation for related questions. Use New session for a different topic.

Quick Questions

The quick-question buttons ask about startup, topomap, timeline, responsibility ownership, and uncertainty.

i
Quick questions are starting points. Follow them with narrower questions about specific files, symbols, or evidence.

Asking Questions

Good questions are specific and ask for evidence.

  • Which file owns this button?
  • Where is the project JSON loaded?
  • Which validator protects this workflow?
  • What is uncertain about this answer?
  • Show the path from the GUI button to the final service call.

Conversations and Memory

New session starts a separate conversation.

Conversations shows previous turns.

Clear memory removes stored Local AI conversation memory.

!
Conversation memory can influence later answers. Clear it when changing projects.

Reading the Answer

Main answer area shows the Local AI response.

File evidence lists relevant files.

Symbol evidence lists relevant symbols.

Selected detail shows more information.

Prompt preview shows what was sent to Local AI.

Log shows runtime events and errors.

What Local AI Can and Cannot Prove

Local AI can summarize and reason about the evidence it receives.

It cannot guarantee that every source file was included, that JSON is current, that runtime behavior matches static source, or that a proposed code change is safe.

Common Mistakes

Common mistakes include asking before loading evidence, selecting an entire drive, using stale JSON, trusting fluent answers without checking evidence, and keeping old memory after changing projects.

If Something Goes Wrong

Check the project root, current JSON, local model service, active request state, profile, conversation memory, and Log.

First-Time Checklist

  • Correct project root
  • Current JSON loaded
  • Local AI configured
  • One focused question
  • File and symbol evidence checked
  • Prompt and Log inspected when needed
  • Uncertainty separated from confirmed evidence

Important Safety Boundary

The Local AI tab does not automatically install patches, edit project files, validate releases, or freeze behavior.

Final Rule

Select the correct project, load current evidence, ask one focused question, and verify the answer before acting on it.
