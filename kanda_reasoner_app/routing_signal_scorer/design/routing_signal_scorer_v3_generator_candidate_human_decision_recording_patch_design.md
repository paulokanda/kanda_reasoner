# Routing Signal Scorer v3 Generator Candidate Human Decision Recording Patch Design v1

This is a schema-only decision-recording patch design milestone for `kanda_reasoner_app/routing_signal_scorer`.

It follows `Routing Signal Scorer v3 Generator Candidate Human Decision Recording Finalization Closure Shield v1` and preserves the closure shield. The current recorded decision remains `not_recorded`.

## Boundary

This patch defines the shape of a future governed human-decision-recording patch. It does not create that future patch and does not write, commit, finalize, or infer any human decision.

## Non-goals

- No decision is written.
- No decision is committed.
- No decision is finalized.
- No decision-recording patch is created.
- No generator candidate patch is created or authorized.
- No generator implementation is authorized.
- No artifact generation, writing, reading, loading, or discovery occurs.
- No source scanning, raw text materialization, embeddings, vectors, providers, runtime scoring, router authority, startup generation, background generation, or public runtime export is added.

## Required future evidence

A future governed decision-recording patch must include explicit human decision text, explicit confirmation to create a decision-recording patch, decision actor/source, timestamp/session reference, scope, referenced freeze IDs, and acknowledgements that generator, artifact IO, source scanning, dependencies, side effects, runtime, and router changes are non-goals unless separately governed.
