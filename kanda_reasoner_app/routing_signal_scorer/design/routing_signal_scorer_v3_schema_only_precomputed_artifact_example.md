# Routing Signal Scorer v3 Schema-Only Precomputed Artifact Example v1

Feature ID: `routing_signal_scorer_v3_schema_only_precomputed_artifact_example_v1`

This is a standard-library-only schema-only static example fixture for the future precomputed semantic evidence artifact family.

The semantic layer remains an untrusted evidence witness.

It may provide evidence. It may never provide authority.

## Purpose

This phase adds a redacted, synthetic, static example shape so future reviewers can see what a valid precomputed semantic evidence artifact may look like without generating an artifact and without enabling any reader, UI, provider, evaluation runner, vector index, embeddings, or semantic runtime behavior.

The example is documentation and validation fixture material only.

The example may never be treated as a generated artifact.

The example may never be loaded at startup or runtime.

The example may never enable semantic runtime behavior.

The example may never tune thresholds or modify routing.

## Allowed content

The example may contain only redacted metadata-style identifiers, synthetic labels, synthetic case references, eligibility statuses, suppression counts, validation gates, disabled flags, and no-authority assertions.

The example may only produce review evidence.

It may never produce a route, required prompts, May-proceed decision, prompt-loading action, threshold change, or freeze-memory write.

## Forbidden content

The example must contain no raw user-query text, private project text, prompt body text, freeze-entry text, terminal log text, embedding values, vector values, vector index payload, provider configuration, model configuration, credentials, or authority fields.

## Frozen source requirements

A future real artifact remains a separate governed phase. Any future artifact must reference a frozen metadata vector manifest schema, frozen offline evaluation gold-set schema, frozen precomputed semantic evidence artifact design, frozen disabled artifact reader boundary, and frozen advisory artifact UI preview boundary.

This phase does not authorize artifact generation.

This phase does not authorize artifact reading.

This phase does not authorize artifact loading.

This phase does not authorize raw text materialization.

This phase does not authorize vector materialization.

This phase does not authorize provider execution.

This phase does not authorize evaluation execution.

This phase does not authorize semantic runtime enablement.

This phase does not authorize threshold changes.

This phase adds no external dependency.
