## Authorization preconditions

A later governed source-file authorization milestone must fail closed unless all of the following are true:

1. MLRT-23 and MLRT-24 are both frozen with `FREEZE_MEMORY_STATUS: OK`.
2. The source target is named exactly and is inside `kanda_reasoner_app/routing_signal_scorer/mlrt_non_runtime_candidate_reliability` or another explicitly governed non-runtime MLRT box.
3. The source target is standard-library-only.
4. The source target is import-isolated from runtime router modules.
5. The source target contains no provider adapters, embedding adapters, network calls, subprocess calls, persistent storage writes, prompt loaders, live canon reads, live freeze-memory reads, or route-decision functions.
6. The source target returns only inert planning, rejection, or not-evaluated states.
7. The source target exposes no authority fields and no approval fields.
8. The source target cannot execute candidates, cases, scoring, route comparison, report generation, or dry runs.
9. The source target does not create fixtures, corpus entries, gold records, candidate packages, output manifests, or reliability evidence.
10. A human review gate confirms this is still non-runtime and non-authoritative.
