# Adviser Seed Gold Set v1

This folder contains the first static offline seed gold set assembled from M9B human-reviewed approval/override records.

It is gold data for offline evaluation only. It does not grant router authority, does not create a candidate scorer, does not run ML, does not auto-load prompts, and does not integrate with runtime routing.

Source chain:

1. M7 seed input cases.
2. M8 draft teacher answers and pending review records.
3. M9B human-reviewed approval/override records accepted from external audit plus human acceptance.
4. M9C seed gold set assembly.

Counts: 50 seed gold cases; 42 approved case-level answers; 8 overridden case-level answers; 0 rejected; 1 cross-cutting governance-path note preserved in source review records.
