# Routing Signal Scorer v3 Auxiliar/Assistant Boundary Design v1

M26 is design-only.

It defines the first explicit Auxiliar/Assistant boundary after the frozen M25
readiness-gate prerequisite design. The boundary permits only future,
non-authoritative human-review support roles to be designed later. It does not
start Auxiliar, Assistant, Pilot, or Copilot behavior.

M26 does not activate shadow mode, integrate with the runtime router, select or
load prompts, compare routes, transform observations, calculate readiness,
record human decisions, write review queues, write reports, mutate gold sets,
mutate registries, call providers, use embeddings, promote candidates, execute
patches, or persist evidence.

A later Assistant may only be introduced through additional governed milestones.
The next allowed milestone is an Auxiliar/Assistant input/output contract design;
it is not Assistant activation.
