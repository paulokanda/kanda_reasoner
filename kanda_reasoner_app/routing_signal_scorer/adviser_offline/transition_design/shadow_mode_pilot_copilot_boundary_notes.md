# M34 - Pilot/Copilot Boundary Design v1

This milestone defines an immutable design-only boundary for a possible later
Pilot/Copilot phase review after the M33 readiness-gate prerequisite design is
validated and frozen.

It does not activate Pilot, Copilot, Assistant, Auxiliar, or shadow-mode behavior.
It does not run a pilot, run a copilot, compare routes, select routes, override
routes, execute routes, select prompts, load prompts, integrate with runtime
routing, inspect runtime state, read or write project files, persist evidence,
write reports, write review queues, record human decisions, mutate gold sets,
mutate registries, call providers, use embeddings, promote candidates, execute
patches, or grant authority.

Allowed content is only a static immutable design record describing future role
limits and hard blocked authority rules. M35 requires separate governed scope
confirmation, validation, and freeze. M34 must not be interpreted as M35, Pilot
activation, Copilot activation, or runtime enablement.
