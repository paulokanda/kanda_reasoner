# ML LAB Charter

## Mission

The KANDA ML LAB is a deterministic, isolated, non-runtime evaluation system to be built in later governed milestones.

Its mission is to test whether future ML/router candidates can:

- reproduce frozen router governance;
- select required prompt groups;
- detect missing context;
- detect stale context;
- reject bypass attempts;
- preserve box boundaries;
- explain disagreements without overriding canon;
- yield to canon;
- produce reproducible audit records;
- fail safely.

## Non-mission

The LAB is not an ML implementation milestone.

The LAB is not runtime Pilot.

The LAB is not Copilot.

The LAB is not activation.

The LAB is not field testing.

The LAB is not prompt loading.

The LAB is not persistence for ML decisions.

The LAB is not a provider-calling system.

## Governance doctrine

```text
ML recommends.
Canon and router governance decide.
Match before disagree.
Critical boundary error budget: zero.
```

## LAB-0 scope

LAB-0 creates the phase boundary and charter only.

LAB-0 may create Markdown documentation and update the routing signal scorer manifest to register the documentation-only box.

LAB-0 may create validation tests that verify the documentation-only boundary.

LAB-0 must not create lab implementation code.
