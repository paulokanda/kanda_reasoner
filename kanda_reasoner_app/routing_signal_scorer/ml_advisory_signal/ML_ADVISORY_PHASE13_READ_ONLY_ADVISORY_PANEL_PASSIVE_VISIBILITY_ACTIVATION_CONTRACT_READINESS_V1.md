# Phase 13 Read-Only Advisory Panel Passive Visibility Activation Contract Readiness v1

This readiness note exists only because Routing Signal Scorer ML Advisory-Signal Phase 12 Read-Only Advisory Panel Runtime App-Host Visibility Completion Handoff v1 closed the Phase 12 runtime app-host visibility descriptor line.

A future Phase 13 contract may define passive app-host visibility activation only if it preserves all governed limits:

- Feature flag default-off.
- Disabled/no-op path.
- Missing descriptor fail-open path.
- Unsafe descriptor blocked/fail-open path.
- Read-only advisory surface only.
- No route influence or route authority.
- No router final-selection hook.
- No provider calls, persistence, prompt-library read, freeze-memory read, or router-canon read.
- No runtime Copilot decision behavior.
- No autonomous ML router.
- No MLRT-113 unless a separate governed risk decision explicitly reopens it.

The Phase 13 contract must distinguish passive read-only visibility activation from route authority, UI mutation outside a bounded passive slot, telemetry surface wiring, host event subscription, host callback registration, and runtime decision behavior.
