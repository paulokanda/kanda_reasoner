The Phase 3 catalog is a small, immutable, synthetic-only fixture catalog for the
already-frozen Phase 2 offline evaluation harness.

It is:

- offline only;
- in memory only;
- non-runtime;
- non-authoritative;
- synthetic only;
- caller-supplied-shape only.

It is not:

- real ML;
- a prompt library reader;
- a freeze-memory reader;
- a router-canon reader;
- a route selector;
- route authority;
- a router prompt logic modifier;
- a prompt loader;
- a prompt registry mutator;
- a provider caller;
- an embedding/vector-store feature;
- a persistence feature;
- MLRT-113.
