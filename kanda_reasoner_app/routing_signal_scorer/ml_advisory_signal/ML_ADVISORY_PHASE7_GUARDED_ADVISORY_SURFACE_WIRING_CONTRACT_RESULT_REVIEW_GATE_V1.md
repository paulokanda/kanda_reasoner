The reviewed contract converted the Phase 7 web-and-book-informed research flux
into a guarded advisory surface wiring contract. It defined future automatic use

unchanged, and it defined a future visible advisory surface only as read-only

## Review result

The reviewed contract is accepted as good and safe only for continued governed
implementation. This review accepts it only as a contract for a future read-only
surface wiring implementation. This review is not as runtime UI wiring and not as advisory panel activation and not as route authority. It is not accepted as runtime UI wiring, not as
advisory panel activation, not as runtime telemetry surface wiring, not as route
authority, not as router prompt logic integration, not as runtime Pilot behavior,
not as runtime Copilot decision behavior, and not as prompt-selection correctness
evidence.

The next implementation must preserve all of these requirements:

- canonical router final selection happens first;
- the canonical router result is copied unchanged;
- only already-computed AdvisoryOutput may be consumed;
- only guarded display payloads may be emitted;
- payload fields are typed, bounded, and schema-like;
- uncertainty, status, role, and scope labels are explicit;
- no free-text route advice;
- no advisory rankings;
- no route override;
- no prompt selection;
- no prompt registry mutation;
- no prompt loading;
- no prompt-library reads;
- no freeze-memory reads or writes;
- no router-canon reads;
- disable/no-op control must exist;
- feedback is non-training feedback only;
- future model/provider activation remains blocked;
- provider, latency, cost, availability, SLO, error-budget, and rollback gates
  remain prerequisites for any later provider-backed work;
- future route influence is limited to a separate deterministic re-check request
  contract, not direct override.
